# Parley CLI Reference

Parley ships no command-line client of its own. Its client is `afc`, the CLI
of `af-hub`, which Parley is API-compatible with; see
[the hub's CLI reference](prd/cli.md) for its commands.

The repository's own commands are the `make` targets, listed by `make help`
and described in [the README](../README.md#develop).
